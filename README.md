# 블로그매니저 — Netlify 버전

화산불백의 세 네이버 블로그(식당창업 성공노트, 오늘 뭐 먹지? 한 끼의 발견, 화산불백 공식블로그)를 관리합니다. 기존 인증·API·사진 편집 기능과 브라우저 저장 형식을 유지합니다.

## Netlify 연결

1. Netlify에서 **Add new project → Import an existing project → GitHub**를 선택합니다.
2. **goldriver365k/blog** 저장소를 선택합니다.
3. 설정은 `netlify.toml`에서 자동 적용됩니다. Build command는 `npm run build`, Publish directory는 `dist`, Functions directory는 `netlify/functions`입니다.
4. 프로젝트의 **Project configuration → Environment variables**에서 아래 값을 등록합니다. 범위를 고를 수 있다면 Functions를 포함하고 Production에 적용합니다.

| 이름 | 값 |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI에서 발급한 새 API 키 |
| `BLOG_MANAGER_PASSWORD` | 본인이 정한 12~256자 관리자 비밀번호. API 키나 네이버 비밀번호와 다른 값 |
| `OPENAI_MODEL` | 선택 사항. 기본 `gpt-4.1-mini` |

5. 값은 비밀값으로 설정합니다. 코드, GitHub, 채팅에 실제 키나 비밀번호를 넣지 마세요.
6. 저장 후 **Deploys**에서 새 배포를 실행합니다.
7. HTTPS 사이트를 열고 **블로그·설정 → OpenAI 연결 확인**에서 관리자 비밀번호로 로그인합니다. 원고 작업의 **OpenAI로 원고 생성**으로 실제 생성을 확인합니다.

파일 끌어놓기만으로는 Functions 서버를 배포할 수 없으므로 GitHub 연동 배포를 사용하세요. API 키를 브라우저에 입력하는 메뉴는 없습니다. 키는 Netlify 서버에서만 사용합니다. 관리자 비밀번호 미등록 시 서버 API는 사용되지 않습니다.

## 기존 원고 이동

기존 사이트에서 **백업 다운로드**를 누르고, 새 사이트의 **블로그·설정 → 백업 복원**에서 파일을 선택합니다. 주소가 바뀌면 브라우저 저장 공간도 달라져 자동 이전되지 않습니다. 백업 파일에 개인정보가 있다면 GitHub에 업로드하지 마세요.

## 비용과 제한

- 별도 데이터베이스, OpenAI SDK, 추가 npm 패키지 없이 동작합니다.
- 원고 생성 버튼을 누를 때만 OpenAI를 호출하고 자동 재시도하지 않습니다. 기본은 응답이 빠른 `gpt-4.1-mini`, 최대 출력 4,000토큰입니다.
- Netlify 동기 Functions의 60초 제한 안에서 동작하도록 OpenAI 연결을 50초에 중단합니다. 시간 초과된 요청도 OpenAI에서 처리됐을 수 있으므로 즉시 반복하지 마세요.
- 관리자 로그인은 8시간 유효한 HttpOnly/Secure/SameSite 쿠키로 보호합니다. 비밀번호 변경과 재배포 시 기존 세션은 무효화됩니다.
- 관리자 비밀번호는 공유하지 마세요. 이 버전은 전역 호출량 제한이나 월 비용 상한을 보장하지 않습니다. OpenAI 계정의 API 잔액과 사용량도 확인하세요.
- Netlify의 요금제 사용 한도와 OpenAI API 비용은 각각 적용됩니다. 무제한 무료 서비스가 아닙니다.
- 원고는 해당 기기의 브라우저에 저장됩니다. 주기적으로 백업하세요.
- 네이버 자동 게시나 예약 등록은 구현하지 않습니다. 공식 편집기에서 사용자가 최종 발행합니다.
- 화산불백 콘텐츠에는 제공받은 실제 사진을 직접 첨부합니다. 기존 Commons 검색 서버는 호환성을 위해 유지하지만 새 원고 생성 과정에서 호출하지 않습니다. CC BY, CC0, Public domain 표기가 확인된 JPEG/PNG/WebP만 선택하고 원본 출처와 저작자·라이선스를 표시합니다. 게시 전 원본의 이용 조건과 관련성을 확인하세요. 사진 결과가 부족하면 적은 수만 배치됩니다.

## 개발

Node.js 22 이상:

```sh
npm run build
npm test
```

`public/index.html`은 화면, `netlify/functions/api.mjs`는 관리자 인증 및 OpenAI 서버 호출, `netlify.toml`은 배포 설정입니다. `/api/ai/*`, `/api/auth/*`, `/api/photos/search` 경로는 Netlify Function의 custom path로 처리됩니다. Sites 전용 인증 헤더나 배포 설정에 의존하지 않습니다.

테스트는 모의 응답만 사용하고 실제 키나 유료 요청 없이 검증합니다. 실제 Netlify 배포와 OpenAI 원고 생성은 환경 변수 등록 후 별도로 확인해야 합니다.

## 사진 직접 넣기

원고 작업의 내 사진 직접 넣기에서 파일 업로드 또는 사진 복사 후 붙여넣기 영역에 Ctrl+V를 사용합니다. 클립보드 버튼도 지원하며 권한 제한 시 Ctrl+V로 진행합니다. JPG/PNG/WebP, 원본 20MB 이하, 글당 선택한 2~3장까지 저장합니다. 긴 변 1600px 이하 JPEG로 변환하고 투명 배경은 흰색으로 바뀝니다. 원본 파일은 별도 보관하세요. 첨부 사진은 서버로 업로드하지 않고 브라우저에 저장되며 백업 JSON과 내보낸 HTML에 포함됩니다. 브라우저 용량이 부족하면 저장을 취소하고 안내합니다. 직접 사진은 자동 검색으로 덮어쓰지 않습니다. 사진 카드에서 삽입 문단과 사진 저장을 선택할 수 있습니다.

## 네이버 핵심 검색어

원고 작업에서 검색어를 쉼표로 구분해 최대 5개 입력합니다. 원고를 생성하면 첫 검색어를 중심으로 제목과 본문에 자연스럽게 반영합니다. 검색어가 지정된 생성은 첫 줄을 제목 입력란에 적용합니다. 원고의 검색어 포함 여부와 등장 횟수를 표시합니다. 기존 원고는 직접 수정하거나 본문 교체 확인 후 다시 생성하세요. 검색량 조회나 네이버 노출 순위 보장 기능은 아닙니다.

## 여러 연재·직접 원고

새 글·원고 넣기에서 제목, 새 시리즈 또는 기존 시리즈, 글 유형을 선택하고 직접 원고를 붙여넣거나 UTF-8 TXT 파일을 불러옵니다. 시리즈가 비어 있으면 단독 글입니다. 연재별 보기로 글을 구분합니다. 다른 주제·자유 글 유형의 AI 생성은 음식장사로 고정되지 않으며 글에 담을 내용 입력란을 참고합니다. 기존 글과 사진은 유지됩니다.

## 2026년 11월 콘텐츠 교체

- 원본 CSV 20편(8/8/4)을 엑셀 발행일정과 교차 검증하여 `public/campaign-data.js`에 보관합니다. 날짜·권장시간·본문·검색어·해시태그·사진 지시·URL을 유지합니다. 운영기간 11/6~12/5, 마지막 원고 12/2.
- 최초 접속 시 각 기기의 전체 원고 데이터를 IndexedDB 백업 보관함에 저장하고 읽기 및 JSON 복원 검사를 거친 후 신규 콘텐츠를 임시 저장·검증하여 교체합니다. 백업 실패·용량 부족 시 기존 데이터를 유지합니다. 이전 서버에 저장되지 않은 브라우저 데이터는 다른 기기에서 접근할 수 없습니다.
- 발행 완료 원고는 그대로 보존하며 삭제·수정을 차단합니다. 교체된 초안의 사진은 사진 보관함으로 이동합니다. 기존 설정·성과 데이터는 유지합니다. 백업 보관함에서 JSON 다운로드/복원할 수 있습니다. 복원 후에는 신규 계획을 자동 재적용하지 않습니다.
- 공식 블로그 아이디는 기존 `bulbaekId`를 유지합니다. 미등록 시 블로그·설정에서 입력합니다. 화면은 음식과 맛 / 음식장사와 외식업 / 화산불백 브랜드의 세 카드로 유지합니다. 운영 블로그의 초기 아이디는 gold365-100이며 음식·브랜드 아이디는 기존 값을 유지하거나 설정에서 입력합니다. 신규 원고는 B1→음식장사, B2→음식과 맛, B3→브랜드로 연결합니다. 네이버 프로필 이름·주제는 네이버에서 직접 설정해야 합니다.
- 월간 달력 클릭·드래그 또는 원고의 날짜 선택으로 일정을 변경합니다. 실제 네이버 예약 이후 일정이 바뀌면 예약 확인 상태를 해제합니다. 프로그램은 네이버에 글을 전송하지 않습니다.
- CSV/XLSX는 로컬 파싱 후 미리보기를 거쳐 추가/교체를 선택합니다. 교체 전 전체 백업과 확인 절차를 수행합니다. 파일 최대 8MB, XLSX 압축 해제 한도 30MB. 외부 수식·매크로·링크를 실행하지 않습니다. fflate는 MIT 라이선스로 동봉합니다.
- 제목 유지 본문 재생성, 문체·분량 선택은 기존 인증된 API를 사용하며 버튼을 누를 때만 호출합니다. 단위·브라우저 테스트는 모의 응답을 사용하며 유료 API를 호출하지 않습니다.
- 방문자·검색 유입·클릭·상담은 블로그/날짜별 수동 입력, 글 조회수는 확인값을 저장합니다. 다음 달 추천은 기록된 검색어·조회수를 사용하며 성과를 조작하거나 네이버를 비공식 수집하지 않습니다.

## 화산불백 AI 전략실

- 세 블로그는 맛·창업·브랜드로 역할을 나눕니다. 기존 게시글, 날짜, 블로그 아이디, API 설정에는 변경을 적용하지 않습니다.
- 검색 후보는 최근 30일에 직접 입력한 유입어 기록과 대조합니다. 네이버 검색·데이터랩 링크에서 검색 의도와 추이를 별도 확인할 수 있으며, 실시간 검색량을 수집하지 않습니다.
- 30일 계획은 8·8·4편까지 미리보고 선택한 글만 빈 날짜에 추가합니다. AI 생성 버튼을 눌렀을 때만 기존 원고 생성 API를 호출합니다.
- 새 원고는 브랜드 연결과 유사 글을 점검하고 검수 대기로 저장합니다. 실제 사진 제안과 해시태그를 제공합니다. 승인에는 기존 관리자 로그인이 필요하며 본문·사진을 수정하면 다시 검수합니다. 네이버 게시와 예약은 직접 진행합니다.
- 최근 7일과 직전 7일의 방문·검색·클릭·상담 기록을 비교합니다. 기록일과 미입력 여부를 함께 표시합니다.
